Add MRCA sampling to an existing generated XML
Date: 2026-11-09
Branch: add-mrca-sampling-script_AI

Added simulate/XMLgenerator/add_mrca_sampling.py, a standalone script using
only the Python standard library and APIs available in Python 3.6.8.

Usage from PHYFUM:
  python3 simulate/XMLgenerator/add_mrca_sampling.py analysis.xml
  python3 simulate/XMLgenerator/add_mrca_sampling.py analysis.xml --suffix _trial
  python3 simulate/XMLgenerator/add_mrca_sampling.py analysis.xml chosen.xml --suffix _trial

The first form creates analysis_MRCASampling.xml next to the input. All
fileName and operatorAnalysis attributes receive the suffix before their
final extension: run.log becomes run_MRCASampling.log, and run.MLE.log becomes
run.MLE_MRCASampling.log. Directory components are preserved. Analysis readers
are renamed along with log writers so MLE/HME references remain consistent.
An explicit second positional path is used exactly as given; --suffix still
applies to analysis filenames inside the XML. Relative analysis paths keep
their original interpretation; the script does not relocate them.

The script finds the likelihood's treeModel root parameter and fixed LCA
height, including parameter idref definitions. It appends a randomWalkOperator
with windowSize=2.5, weight=3, boundaryCondition=reflecting, autoOptimize=true,
and upper equal to cenancestorHeight. There is no explicit lower limit:
TreeModel supplies the live oldest-child bound. Existing operators, rates,
priors, and data are retained. In-document XML comments are preserved;
ElementTree can normalize XML formatting and quote style.

Inputs must define one cenancestorTreeLikelihood with heightRules=true and
one operator schedule, a positive finite scalar LCA height, and an identified
root-height parameter. Sampled LCA parameters and existing root random walks
are rejected. Empty suffixes and suffixes containing path separators are
rejected. The input cannot be overwritten, and output creation is exclusive
to protect existing files.
