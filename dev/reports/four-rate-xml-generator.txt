Four-rate XML generator and example
Date: 2026-10-08
Branch: four-rate-params_AI

Usage (from PHYFUM)
-------------------
  python simulate/XMLgenerator/methylationBetas2xml.py \
    --input samples.csv --age 45 --four-rates --output analysisFourRates

Optional --nu and --zeta set their initial values, for example:
  python simulate/XMLgenerator/methylationBetas2xml.py \
    --input samples.csv --age 45 --four-rates --nu 0.04 --zeta 0.08 \
    --output analysisFourRates

The four rates are mu, nu, gamma, and zeta; lambda remains the independent
cell-replacement rate. Without --four-rates, the generator retains its original
output and PHYFUM ties nu to mu and zeta to gamma. In four-rate mode, unspecified
nu/zeta initial values are copied from mu/gamma, but distinct XML parameters
allow their subsequent estimates to differ. --nu/--zeta require --four-rates.
The Python API offers four_rates=True with optional nu and zeta arguments.

Sampling configuration
----------------------
Nu uses mu as its template; zeta uses gamma. Both reference rates currently use:
  - Nonnegative parameter bounds.
  - Independent scaleOperator: scaleFactor=0.9, weight=0.5.
  - halfNormalPrior: mean=0.0, stdev=0.05.
The new rates also enter the existing upDownOperator's up group alongside
mu, gamma, and lambda, preserving joint scaling of all rates against tree time.
Both are included in the parameter log. Existing MLE configurations use the
same expanded prior, so the new rates have proper priors there as well.

Example
-------
examples/release/flipflop/sim1AbsoluteFourRates.xml is derived from
sim1Absolute.xml with these equivalent additions. It preserves the original
data, initial parameter values, chain length, and other model settings, and
uses sim1AbsoluteFourRates.ops/.log/.trees for its outputs. The original
sim1Absolute.xml remains unchanged.
